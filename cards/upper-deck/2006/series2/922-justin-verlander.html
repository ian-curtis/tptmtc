The Play

April 23, 2006

Detroit Tigers @ Seattle Mariners

Unknown

Verlander throws a pitch.

From the photo, we can see Verlander is wearing jersey number 35 and this is a day game. Verlander did wore 35 starting in 2006 and since this card came out in late 2006, we can assume the photo was taken earlier that year. Verlander pitched in a few away day games but we can use the white advertisement in the background to narrow this down to one game. From this photo of Joel Pineiro (a Mariners pitcher) we can see the exact same advertisement in the background. Verlander it there for depicted in a day game in Seattle which only occurred on April 23.
